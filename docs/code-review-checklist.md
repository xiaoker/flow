# Flow 代码审查清单

本清单用于发现影响数据可信度、用户判断和运行稳定性的问题。审查者按本次差异选择适用项，并复用已有测试、PR 和阶段报告中的证据；不要求每次重新采集数据或重做全系统审计。

## 使用规则

- 本清单不是新增的审批、授权、CI 或生产门禁，不改变用户已有授权、实施计划的停止点及现有质量校验。
- 不适用项标记 `N/A` 并简述原因；未验证项标记 `UNKNOWN`，说明影响和后续动作。不得把未知写成通过。
- 清单文件、审查技能或辅助工具缺失时，继续使用人工审查和仓库真实可用的检查；不得仅因此阻断实施、要求重复授权或安装另一套流程。
- 只有发现具体缺陷或现有强制合同未满足时，才按实际影响处理阻点。阻点应写清证据、影响范围和最小修复，不以勾选数量判断是否完成。
- 文档、样式等低影响改动只检查相关项；涉及日期、公式、发布、权限或生产写入时，检查对应合同和失败路径。
- 不在审查过程中顺便补采、改生产状态或扩大阶段；审查不会授予新的生产操作权限。

## 1. 数据来源、日期与计算口径

- [ ] 调度窗口日期、真实数据日期、来源发布日期、净值/PCF 日期和观测时间的用途明确，未互相替代。
- [ ] 名称、代码、市场、单位和转换规则有来源；不同货币、份额与股数未直接混加。
- [ ] 公式和分类复用现有版本合同；改变口径时有版本和可复算样例。
- [ ] 多个页面或数据域的日期兼容性有证据，未把一个域的可见性当成其他域完整。

## 2. 缺失数据与产品表达

- [ ] 空值、真实零值、来源未到、失败和历史不足能区分；未用前值、零值或估算冒充真实数据。
- [ ] 周期所需交易日、基准节点、可比样本和实际覆盖按各自口径表达，未用样本数代替日期覆盖。
- [ ] 不完整周期说明实际限制；不猜缺失日期，不把全工件计数分摊为每个周期的覆盖。
- [ ] 估算持仓、份额变化、申赎估算和实际成交资金的标签准确；用户能看懂适用范围。

## 3. 工件、版本与发布一致性

- [ ] 工件日期、releaseId、schema/contract 版本、哈希和来源指纹按现有合同校验。
- [ ] 不同版本、日期或 slot 的响应不会混用；过时请求、缓存和重试不会覆盖当前选择。
- [ ] 发布失败保持已有完整版本；候选验证通过不被误报为生产验收通过。
- [ ] 状态完成有真实结果证明，重复执行和失败恢复遵守现有幂等、租约与质量规则。

## 4. 查询和资源消耗

- [ ] D1 查询使用适当索引、限定范围；R2 列举/读取有分页、条数和字节上限。
- [ ] 重复调度、轮询、重试和历史任务不会无界放大读写、请求或 Actions 分钟。
- [ ] 资源估计说明范围与依据；缺少账户用量时保留 `UNKNOWN`，不宣称免费额度已验证。
- [ ] 复用已归档证据与计算结果；没有为审查无端触发全量采集或历史重建。

## 5. 权限与秘密

- [ ] 接口沿用现有认证，权限与读取/写入范围相符；未认证和错误身份有拒绝路径。
- [ ] Token、密钥和敏感运行信息不会进入日志、URL、仓库或错误响应。
- [ ] 浏览器使用管理密钥时明确实际暴露范围与清除方式，不声称未经验证的隔离或最小权限。
- [ ] feature flag 默认值、启用条件和生产读取边界符合当前阶段约定。

## 6. 验证、部署副作用与回滚

- [ ] 检查针对实际风险，覆盖关键成功/失败路径；未降低断言或用 mock 成功代替生产验证。
- [ ] 使用仓库真实命令，记录测试结果；本地、CI、候选和生产验证分别描述。
- [ ] 列明合并自动触发的部署、migration 和其他任务；无新增 migration 不等于远程无待执行 migration。
- [ ] 说明回滚方式和数据兼容性；遵守原工作区保护、阶段边界和已有授权。

## 简短审查记录

在现有 PR 描述或阶段报告中记录即可，无需额外建表或重复提交材料：

```text
审查范围：分支/提交及相关文件
适用项：上述章节或具体检查项
证据：测试结果、代码位置或已有工件链接
发现：缺陷 / UNKNOWN / N/A，以及实际影响
处理：已修复或后续归属；现有合同导致的阻点及理由
部署影响：自动动作、生产变化、回滚方式（无影响可写 N/A）
```

数据字段的历史复算样例见 [数据血缘与人工核对表](data-lineage-manual-checklist.md)；分支和部署约束见 [分支同步与发布约束](branching-and-release.md)。历史审计中的结论只适用于其记录的版本和时点，不作为当前生产状态的证明。
